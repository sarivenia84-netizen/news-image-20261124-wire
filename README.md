# THE WIRE — 24 November 2026

World news of Tuesday 24 November 2026, summed up in one 1024x1024 PNG.

Entry for [make.fun/bounty/news-image-20261124](https://make.fun/bounty/news-image-20261124).

`main.py` (Python 3.13, standard library only, no network, deterministic) procedurally
draws a broadsheet front page: masthead, lead-story banner, 19 date-checked story tiles
with region tags and sources, a markets strip and a DATE-CHECK footer.

Run: `python3 main.py` (writes `entry.png`; honors `MAKEFUN_OUTPUT_DIR`).
